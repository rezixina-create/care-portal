# 介護施設 統合業務ポータルシステム (Care Portal)

介護現場の日々のケア記録・バイタル・申し送り管理から、事務所の消耗品在庫・預り金出納・公用車運行・法定監査業務までを一元管理できる統合Webアプリケーションです。

---

## 🌟 主な機能

### 1. 介護現場ポータル
- **📝 介護記録**: B5用紙1枚分の日報・カルテ対応、リアルタイム文字数カウント、全画面集中入力、印刷フォーマット
- **🩺 バイタルチェック表**: 体温、血圧、脈拍、SpO2のリアルタイム入力・個人記録連動
- **🍚 食事・水分 / 🚽 排泄 / 💊 服薬・点眼**: チェック・記録管理
- **📋 連絡帳・申し送り**: 申し送りの一覧・完了ステータス、長方形ネーム印による確認機能（取り消し・解除対応）
- **👤 利用者管理**: 
  - 新規利用者登録（居室、氏名、介護度、アレルギー、既往歴、方針、緊急連絡先など）
  - カルテ情報編集
- **👥 職員・認印管理**: 役職・序列順（施設長・管理者筆頭）の自動整列、新規職員追加、手動並び替え、退職・削除

### 2. 事務所ポータル
- **📦 消耗品在庫管理**: 小分けバラ単位在庫、安全基準数アラート、納品・入出庫ログ
- **💰 預かり金出納帳**: 利用者ごとの残高表示、日付連動、履歴絞り込み
- **🚗 送迎・公用車運行管理**: メーターkm自動計算、鍵返却確認
- **📑 発注申請ワークフロー**: 申請から上司承認、納品受領までのワークフロー
- **🏭 取引先マスタ**: 業者名・連絡先・取扱品目の登録・編集・削除
- **⚠️ ヒヤリハット・事故報告書**: 法定記録の保管・編集

## 🚀 起動方法

### Windows
`run_portal.bat` をダブルクリックして起動します（**これ1つをクリックするだけで完了**）。
ローカルサーバーと外部接続トンネル（Cloudflare Tunnel）が同時に自動起動し、ブラウザが自動的に開きます。

ご自宅のWi-Fi・学校・外出先スマホ（4G/5G）など、ネットワーク環境を問わず、画面右上の「📱 接続案内」に表示される**統一QRコードまたはURL1つで即座に共有・操作**できます。

または PowerShell から：
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
